
# SpendWise Budget Tracker

## Project Description

SpendWise is a simple budget tracking application
that helps users manage their monthly budget.

Users can set a budget, add expenses, calculate
total spending and view their remaining balance.

## JavaScript Concepts Used

1. Variables
2. Data types
3. Arrays
4. Objects
5. Functions
6. Loops
7. Conditional statements
8. User input
9. Event listeners
10. DOM manipulation

## How Variables Are Used

The variable `budget` stores the monthly budget.

The `expenses` array stores all expenses entered
by the user.

Each expense is stored as an object containing
its name and amount.

## How User Input Is Collected

The JavaScript `prompt()` function collects
the monthly budget from the user.

HTML input fields collect expense names and
expense amounts.

## How Calculations Are Performed

The application adds all expenses using the
`calculateTotalExpenses()` function.

The remaining balance is calculated by subtracting
total expenses from the monthly budget.

Remaining Balance = Budget - Total Expenses

## How Functions Organize the Code

The application uses different functions:

- `calculateTotalExpenses()` calculates total spending.
- `calculateBalance()` calculates the remaining balance.
- `displayExpenses()` displays expenses.
- `updateDashboard()` updates the dashboard.
- `formatMoney()` formats amounts in Kenyan Shillings.

Functions make the code organized, reusable
and easier to understand.

## How to Run the Project

1. Download the project files.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Set your monthly budget.
5. Add your expenses.
6. Check your remaining balance.
7. Open the browser console to see calculation results.
